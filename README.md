# Ali Algarea - Professional CV Website

A modern, responsive CV website showcasing professional experience, skills, and achievements.

## 🌐 Live Website

Your website is ready to be deployed! Follow ONE of the options below:

## ⚡ OPTION 1: GitHub Pages (RECOMMENDED - 2 clicks!)

### Quick Steps:
1. **Click this link:** https://github.com/aalwaily/Ali/settings/pages
2. **Under "Build and deployment" → "Source"**, select:
   - Source: **Deploy from a branch**
   - Branch: **`claude/gh-pages-011CUa7PejWtEEVx7Grhc3Ug`**
   - Folder: **`/ (root)`**
3. **Click "Save"**

### Your website will be live at:
```
https://aalwaily.github.io/Ali/
```
(Takes 1-2 minutes to go live)

---

## 🚀 OPTION 2: Netlify Drop (30 seconds - EASIEST!)

1. **Download** the `index.html` file from this repository
2. **Go to:** https://app.netlify.com/drop
3. **Drag and drop** the `index.html` file
4. **Done!** Get instant URL like: `https://ali-algarea-cv.netlify.app`

## 📋 Alternative: Merge to Main Branch (Recommended)

For a cleaner setup:

1. Go to your repository: `https://github.com/aalwaily/Ali`
2. Click **"Pull requests"** → **"New pull request"**
3. Click **"compare across forks"** or change base
4. Set base to: `main` (or create it)
5. Set compare to: `claude/create-cv-website-011CUa7PejWtEEVx7Grhc3Ug`
6. Click **"Create pull request"** → **"Merge pull request"**
7. Then in Settings → Pages, select `main` branch instead
